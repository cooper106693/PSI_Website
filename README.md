# PSI Website

Static HTML/CSS site for the Partnership for Scientific Inquiry. This website was create using LLM assisted coding tools. All written content and images on this page is created by the PSI leadership team.

The site is deployed automatically to GitHub Pages whenever `main` changes. Each page is a directory with its own `index.html`, so the original routes remain available:

- `/about/`
- `/leadership/`
- `/application/`
- `/faq/`
- `/important-dates/`
- `/contact/`
- `/awards/`
- `/collaborations/`
- `/testimonials/`
- `/previous-lectures/`
- `/alumni-achievements/`
- `/lewis-scholars/`
- `/media/`
- `/donate/`
- `/visitor-analytics/`
